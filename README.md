## Sobre mí

Estudiante de Ingeniería en Informática en **DuocUC**. Construyo productos full-stack de punta a punta: intranets corporativas con control de acceso por roles y mensajería en tiempo real, bots de Discord con panel web, aplicaciones de escritorio local-first y pipelines de análisis de datos.

Cada proyecto suele vivir completo en un mismo repositorio: la API, la interfaz, el esquema de base de datos y el setup de Docker que lo levanta. Actualmente profundizo en **Rust** y **Astro**.

## Aprendiendo actualmente

**Rust** — ownership y borrowing, APIs a nivel de sistema y herramientas de escritorio nativas mediante Tauri.
